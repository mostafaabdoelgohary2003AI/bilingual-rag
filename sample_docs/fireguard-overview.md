# FireGuard — graduation project overview

FireGuard is the graduation project of the Faculty of Artificial Intelligence,
Cairo University (class of 2026). It is a fire and smoke detection
system: a YOLO-based computer-vision model analyses camera frames and sends
alerts to a mobile application when fire or smoke is detected.

The project was built by a team of eight students and was graded Excellent
with Honors. The backend was written in Python.

Omar's individual role on the team was deployment. He was responsible for
hosting the backend on PythonAnywhere so that the mobile application and the
detection model could work together online. The main engineering challenge was
making separate components, built by different team members, run together
reliably in one deployed environment.

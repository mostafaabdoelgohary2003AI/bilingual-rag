# تحليل شحن السيارات الكهربائية في وارسو

مشروع تحليل بيانات لحوالي 114 ألف جلسة شحن للسيارات الكهربائية مسجلة في
محطات الشحن العامة في مدينة وارسو. يستكشف التحليل مدة الجلسة، والطاقة
المستهلكة، ونسب استخدام المحطات على مدار اليوم، وفترات ذروة الطلب.

تم العمل بلغة بايثون باستخدام مكتبات pandas وNumPy وMatplotlib وSeaborn،
وبمساعدة أدوات الذكاء الاصطناعي في كتابة الكود. النوت بوكس الكاملة والرسوم
موجودة في مستودع GitHub المرافق.

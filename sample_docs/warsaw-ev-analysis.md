# Warsaw EV charging analysis

A data-analysis project over roughly 114,000 electric-vehicle charging
sessions recorded at public charging stations in Warsaw. The analysis
explores session duration, energy delivered, station utilisation over time,
and peak demand windows.

The work was done in Python with pandas, NumPy, Matplotlib and Seaborn, and
developed with AI-assistance (pair-programmed with an LLM assistant). The
full notebooks and figures live in the companion GitHub repository.
